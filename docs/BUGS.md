# Найденные дефекты

Дефекты воспроизводятся под учётной записью `problem_user` и закрыты автотестами
с `@pytest.mark.xfail(strict=True)` — если поведение починят, тест упадёт
и заставит обновить документацию.

Проверить вручную: [saucedemo.com](https://www.saucedemo.com/), логин
`problem_user`, пароль `secret_sauce`.

---

## BUG-101 — Все карточки товаров показывают одно изображение

| | |
|---|---|
| **Severity** | Major |
| **Priority** | High |
| **Компонент** | Каталог, `/inventory.html` |
| **Тест** | `test_product_images_are_unique` |

**Шаги воспроизведения:**
1. Войти под `problem_user`.
2. Открыть каталог.
3. Сравнить атрибут `src` у изображений всех шести карточек.

**Ожидаемый результат:** у каждого товара своё изображение — шесть разных `src`.

**Фактический результат:** все шесть карточек ссылаются на одну картинку,
уникальных значений `src` — 1 из 6.

**Влияние:** товары визуально неразличимы. Для магазина это прямая потеря
конверсии: покупатель не видит, что заказывает.

## BUG-102 — Сортировка каталога не применяется

| | |
|---|---|
| **Severity** | Major |
| **Priority** | High |
| **Компонент** | Каталог, выпадающий список сортировки |
| **Тест** | `test_sorting_works_for_problem_user` |

**Шаги воспроизведения:**
1. Войти под `problem_user`.
2. Выбрать в списке сортировки «Name (Z to A)».
3. Посмотреть порядок товаров.

**Ожидаемый результат:** товары переставлены по убыванию названия,
первым идёт «Test.allTheThings() T-Shirt (Red)».

**Фактический результат:** порядок не меняется, первым остаётся
«Sauce Labs Backpack». То же самое для остальных вариантов сортировки.

**Влияние:** пользователь не может упорядочить каталог. В магазине с большим
ассортиментом это делает подбор товара практически невозможным.

## Замечание по методике

Оба дефекта заложены в стенд намеренно — SauceDemo для того и сделан.
Ценность здесь не в самой находке, а в том, что расхождение
зафиксировано тестом, который не даст ему тихо «починиться» или
незаметно измениться.
